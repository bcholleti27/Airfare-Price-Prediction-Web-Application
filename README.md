# Airfare Price Prediction Web Application

A full-stack machine learning web application for predicting
airline ticket prices using historical airfare data.

## Project Overview
This project aims to help users estimate flight ticket prices
based on travel details and historical pricing patterns.

## Technologies
- Python
- FastAPI
- Pandas (planned)
- scikit-learn (planned)
- TensorFlow / LSTM (planned)
- React.js (planned)
- HTML5, CSS3, JavaScript

## Planned Features
- Flight search interface
- Departure and destination selection
- Travel date selection
- Airfare price prediction
- Historical airfare data analysis
- Machine learning model integration

## Current Progress
- Initial Python backend created
- REST API endpoints defined
- Backend dependencies added
